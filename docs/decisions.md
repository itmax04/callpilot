# Существенные решения

1. Demo-ответы привязаны к `call_id`, чтобы бесплатный режим был воспроизводим и не выдавал фикстуру за модель.
2. SQLite используется по умолчанию для быстрого локального сценария, SQLAlchemy и Docker Compose сохраняют PostgreSQL-путь.
3. CRM не передаётся провайдеру: оценка относится к разговору, а связь/стадия остаются аналитическим слоем.
4. Цитаты проверяются точным совпадением с исходной репликой; отсутствие действия описывается объяснением без выдуманной цитаты.
5. Две версии промпта фиксированы до сравнения; discrepancies включает регрессии и ошибки доказательств.

6. Live использует официальный `client.responses.parse(..., text_format=ModelPayload)` и `output_parsed`; схема Pydantic передаётся SDK, а отказы/неполный ответ считаются ошибкой без demo-fallback. См. [официальное руководство Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
