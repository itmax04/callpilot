# Демонстрация за 5 минут

1. Показать `data/transcripts/` и `data/problematic/`, затем запустить `python -m callpilot.cli all`.
2. Открыть `outputs/manifest.json`: найти дубль, пустой JSON, unknown deal и injection.
3. Открыть отчёт и объяснить формулу score, coverage и отсутствие live-метрик.
4. Запустить Streamlit, открыть карточку CALL-001 и показать точные `utterance_ids`/quotes.
5. Открыть discrepancies CSV, SQL и рассказать, какие три проверки нужны перед реальным пилотом.
