# Data card

Все записи синтетические, созданы для демонстрации и не являются клиентским пилотом. 24 звонка на русском/украинском, 12 сделок по два звонка. Дополнительные файлы содержат точный дубль, пустой и некорректный JSON, отсутствующий/неизвестный deal_id и prompt-injection как обычный текст.

Манифест хранит относительный путь, SHA-256, статус и причину. Исходники не меняются. Дубли повторно не анализируются. Текст с отсутствующей CRM-связью анализируется как текст и получает предупреждение; в demo для двух таких фикстур есть отдельные ответы. Инструкция из prompt-injection передаётся провайдеру как недоверенная реплика. Development — CALL-001..008 (4 сделки), holdout — CALL-009..024 (8 сделок); связанные звонки не разделяются.

Эталонные ответы синтетические, подготовлены с помощью AI-фикстур и требуют человеческой проверки; это не независимая экспертная разметка.
