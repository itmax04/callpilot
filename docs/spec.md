# Спецификация

Входы: JSON-файлы расшифровок с `call_id`, `deal_id`, датой, языком и репликами; CSV CRM (`deal_id`, `manager_id`, `stage`, `amount`, `currency`). Выходы: manifest, оценки по 7 критериям, SQL-данные, метрики, discrepancies CSV и Markdown-отчёт.

Готовность MVP: demo проходит без ключей; дубли исключены; пустые/некорректные записи видны; CRM не блокирует текст; цитаты проверяются; нулевой знаменатель возвращает отсутствие оценки; повторный запуск идемпотентен; UI читает результаты; тесты проходят. Live и Azure — отдельный статус готовности.
