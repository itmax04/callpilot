# Оценивание

`score = met / (met + not_met)`; `not_applicable` и `insufficient_data` исключаются из знаменателя. При нулевом знаменателе score отсутствует. Coverage = число критериев с usable-решением / (число звонков × 7).

Accuracy — доля совпавших статусов по всем 7×24 сравниваемым ячейкам. Macro-F1 — среднее F1 четырёх классов со всеми классами в знаменателе. Некорректные цитаты считаются среди цитат, которые модель предоставила для проверки. Неуспешные live-вызовы не исключаются молча: они попадают в `calls_failed`, а строки получают статус failed.

v1 — краткая рубрика; v2 — пограничные правила и требования доказательств. Запуск: `python -m callpilot.cli all`; таблица расхождений — `outputs/discrepancies.csv`. Текущие цифры генерируются при запуске и лежат в `outputs/summary.json`; без live-запуска live-метрик нет. Holdout мал и синтетичен, не является независимой итоговой проверкой; промпты после него не меняются.
